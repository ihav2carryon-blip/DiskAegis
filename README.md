# DiskAegis (神盾智盘)

DiskAegis 是一款基于大语言模型（LLM）语义感知与系统底层轻量分析引擎构建的智能化磁盘空间与运行内存治理桌面应用。项目原生支持 OpenAI 与 Anthropic 双协议规范，能够深度适配 DeepSeek、Claude、GPT 系列模型及各类兼容中转服务。

---

## 项目背景

在日常数字化办公、软件工程、数字艺术创作与科研工作中，系统磁盘（尤其是 Windows C 盘与工作盘）常常面临以下痛点：

1. **传统清理工具规则僵化**  
   现有的系统自带清理或常见清理软件多基于硬编码规则，仅能清理系统临时文件或浏览器缓存，无法识别现代专业软件产生的大量高阶冗余（如包管理器缓存、大型依赖产物、版本控制留存、工程中间构建物、废弃虚拟环境等）。

2. **缺乏行业与使用场景认知**  
   不同职业对资产的重要性定义截然不同。对于软件工程师，废弃工程中的构建缓存与中间包属于可清理资产；而对于财务、法务或科研人员，相关文档、数据模型与凭证哪怕属于临时生成也具备极高保护等级。传统工具无法区分使用者的职业背景，容易出现“无用的不敢删，有用的被误删”的困境。

3. **自然语言交互与自定义规则缺失**  
   用户往往有明确的个性化边界（例如“保留某特定软件的所有数据”、“某个工程目录下的构建产物可以删除”），传统工具无法理解用户的自然语言意图。

4. **物理内存（RAM）常驻占用过高**  
   多任务并行下，后台闲置应用常驻工作集过大，导致系统响应迟滞，缺乏快捷的安全压缩与释放手段。

基于上述痛点，**DiskAegis** 结合了底层轻量级原生扫描能力与大语言模型的语义裁决能力，引入职业画像自适应与自然语言安全防护铁律（Guardrails），让磁盘与内存治理兼具深度释放力与数据安全性。

## 核心功能

### 1. 语义感知与资产裁决中枢
- **双标准协议原生支持**：
  - OpenAI 兼容协议：适配 DeepSeek 官方端点、OpenAI 官方、各类第三方 OneAPI/NewAPI 聚合网关及本地私有化模型（如 Ollama）。
  - Anthropic Messages 协议：适配 Anthropic 官方及兼容端点。
- **自定义 Base URL**：用户可自由配置与修改目标服务的 API 端点地址，无需修改任何源码。
- **思考模式（Thinking Block）兼容**：针对新一代具备推理链（Reasoning）的模型，提供结构化答案过滤提取机制，避免格式解析异常。

### 2. 职业画像与场景自适应
- 系统内置通用办公、财务法务、影视剪辑、视觉设计、软件开发与学术科研等主流数字化职业画像。
- 结合所选职业特性，大模型动态调整判定倾向，精准识别各类特定软件的缓存、媒体临时工程与环境构建废弃物。

### 3. 最高优先级自然语言防护铁律（Guardrails）
- 支持用户使用自然语言直接输入删除意图与保护边界。
- 具备一票否决权：内置正则动态意图提取器与大模型双重校验机制，用户明确指示保护的项目绝对锁定，严禁列入清理计划。

### 4. 磁盘容量实时透视与靶向深度扫描
- 毫秒级探测 Windows 物理磁盘总容量、已用空间与可用空间。
- 基于轻量级原生脚本实现靶向穿透扫描，数秒内检出数十至上百 GB 的可释放大体积候选资产。

### 5. 运行内存监控与工作集一键压缩
- 实时获取物理内存负荷率与空闲量。
- 动态列举系统内存占用最高的 TOP 8 进程。
- 调用底层进程工作集收缩接口，一键安全回收闲置常驻内存。

### 6. 交互式安全审核与零误删机制
- 全维度信息呈现：文件路径、体积、修改时间、推荐状态与判定依据。
- 支持全选、反选、仅选推荐项等快捷操作。
- 核心系统关键目录（如系统根目录、Windows 系统文件夹等）具备底层写保护白名单机制。
- 执行前弹窗二次人工确认，物理删除后自动复测磁盘容量并生成释放报告。

- 运行环境：Node.js 18.0.0 或更高版本
- 网络环境：需访问配置的 AI 接口端点（如配置本地模型则无需公网连接）

## 快速开始

### 1. 克隆代码仓库

```bash
git clone https://github.com/ihav2carryon-blip/DiskAegis.git
cd DiskAegis
```

### 2. 安装项目依赖

```bash
npm install
```

### 3. 运行应用程序

项目提供了多种运行方式，可根据实际需求选择：

#### 方式 A：Windows 双击运行（推荐）
- 双击根目录下的 `启动应用.bat`：自动校验环境并以桌面客户端形式启动。
- 双击根目录下的 `静默启动.vbs`：无控制台黑框直接拉起应用。

#### 方式 B：Electron 桌面窗口运行
```bash
npm run electron
```

#### 方式 C：本地 Web 服务模式
```bash
npm start
```
启动后在浏览器中访问：`http://localhost:3928`

## 使用指南

### 第一步：配置 AI 接口
1. 打开应用程序，在界面顶部的“AI 模型与接口配置”区域：
   - 选择接口调用协议（OpenAI 兼容协议 或 Anthropic 协议）。
   - 填写 Base URL（提供常用快捷选项，亦可完全手动输入）。
   - 填入对应的 API Key（支持快捷跳转申请页面）。
   - 输入或选择目标模型名称（如 `deepseek-v4-flash`、`deepseek-chat` 等）。
2. 点击“保存配置”，配置将实时生效并保存在本地 `config.json` 中。

### 第二步：设定职业画像与自定义防护提示词
1. 在“职业画像与自定义提示词”区域，选择契合你当前电脑用途的职业角色。
2. 在自定义提示词输入框中输入你的自然语言指令，例如：
   ```text
   绝对不要碰微信文件、工作文档和Steam游戏；各类开发包缓存、中间构建物和过期安装包可以放心删除。
   ```
3. 系统将即时持久化该规则，并在后续扫描中赋予该规则最高仲裁权。

### 第三步：运行内存一键优化
1. 在“运行内存 (RAM) 监控”看板中查看当前物理内存负荷与 TOP 内存占用进程。
2. 点击“一键内存极速优化”按钮，系统将自动触发闲置工作集回收，瞬间降低系统负载。

### 第四步：磁盘扫描与 AI 语义裁决
1. 点击“开始全盘智能扫描分析”按钮。
2. 系统底层扫描引擎将迅速对磁盘进行靶向探查，随后调用配置的大模型对每一个候选资产进行背景结合研判。
3. 界面上方的 AI 实时监听器将直观展示当前请求端点、协议格式与处理耗时。

### 第五步：人工复核与安全清理
1. 扫描完成后，在结果列表中审阅各项资产的详细信息与 AI 判定理由。
2. 可通过筛选栏快速查看“建议清理”或“重点保护”项目，自由调整勾选状态。
3. 确认无误后点击“执行安全清理”，在二次确认弹窗中核对拟删除项目总数与预估释放体积，确认后物理执行。
4. 清理完成后系统将复测磁盘最新容量并生成清理成效摘要。

如需将本项目构建为无依赖的 Windows 独立桌面发行包：


## 安全与隐私规范

1. **密钥本地私有化**  
   用户的 API Key 仅保存在本地的 `config.json` 文件中，所有对外网络请求均由本机直接与用户配置的 Base URL 通信，不存在任何第三方中间转发服务器，杜绝数据泄露风险。
2. **源码仓库隔离**  
   工程自带完备的 `.gitignore` 规则，`config.json` 与本地构建产物已被严格排除在版本控制之外，推送至公开代码仓库时不会泄露任何个人凭证。
3. **关键系统防护**  
   系统内置了对 Windows 系统核心路径（如 `Windows`、`Program Files`、驱动根目录等）的强力白名单防护，防止破坏系统稳定性。
4. **决策审核权归属用户**  
   AI 的裁决仅作为辅助建议，未经验证确认的项目绝不会被静默移除，保障用户数据的绝对掌控权。
